How to Test Your Network Using Ping in Packet Tracer

Follow these beginner-friendly steps to verify communication

Method 1

Using the Command Prompt inside a PC

  1. Open {{ output_filename }} in Cisco Packet Tracer.
  2. Click on PC1 (or any PC).
  3. Switch to the Desktop tab and click Command Prompt.
  4. Type ping {{ plans[0].gateway_ip }} to test the local default gateway.
  5. Type ping {{ plans[-1].assignments[-1].ip }} to test pinging across subnets to {{ plans[-1].assignments[-1].device_name }}!
Method 2

Using the Pre-configured Ping PDUs

Our application automatically placed ICMP Echo PDUs inside the file! Look at the bottom-right corner of Packet Tracer under User Created Packet Window. Click the Fire button or switch to Simulation Mode to watch packets travel across the switches and router!

💡
Why does the first ping show "Request timed out"?

This is completely normal in computer networking! Switches run STP (Spanning Tree Protocol) which takes ~30 seconds to transition switchports from Blocking → Listening → Learning → Forwarding (green lights). Additionally, routers and PCs send ARP (Address Resolution Protocol) broadcast requests to learn MAC addresses before ICMP packets can be transmitted. If the first ping times out, simply press the Fast Forward Time button (>> in the bottom toolbar) or re-run the ping!
